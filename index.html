# The thesis

by: Name

## A contributing factor
slug: a-factor
importance: 60
impact: 0.8
confidence: 4
basis: What would change my mind about it

- [ref] [Source name](https://example.org) — optional note

slug: its-child

by: Name

slug: another
importance: 70
impact: -1

# Or a proposition with premises
slug: which-way

## First premise
slug: premise-one
kind: premise

### Why it holds
slug: why-one
importance: 60
impact: 0.6

## Second premise
slug: premise-two
kind: premise

One # more per level, with properties directly under the heading. importance is relative to the fact's siblings, and impact runs from -1.0 (contrary) to 1.0 (supporting). A root can instead hold premises, marked kind: premise, whose values are calculated from their children. Each file has one root; the second one above shows the other kind of map. Older list-style files still open, and are saved in this format.
